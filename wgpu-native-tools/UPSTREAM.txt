WHAT THIS FOLDER IS
--------------------------------------------------------------------------------
wgpu-native/ is an unmodified copy of two official upstream archives:

  wgpu-native/                    wgpu-native v29.0.1.1 (gfx-rs) - the C API of
                                  wgpu over wgpu-core 29.0.3. Not on crates.io
                                  (its package version is 0.0.0), hence vendored.
  wgpu-native/ffi/webgpu-headers/ webgpu-headers @ 673658bc2bd70ec39fc55ebe6bb0173cf6d0a603
                                  - webgpu.h, webgpu.yml (the binding generator's
                                  input), schema.json; the git SUBMODULE wgpu-native
                                  v29.0.1.1 pins. The release archive carries the
                                  submodule folder EMPTY, so it is fetched from its
                                  own repository at exactly that commit.

Everything else the build compiles comes from crates.io, pinned by
codebrix-wgpu/Cargo.lock (version + sha256 checksum of every crate; the
2026-10-11 ruling: crates.io crates are "NuGet packages for Rust" and are not
vendored). No git-sourced or out-of-repository crate is in the lock.

No build step downloads either tree. refresh-upstream.sh is the only script
that does (to bump or re-verify them); the archives are kept byte for byte in
upstream-downloads/ so the trees can be re-verified with no network.

This file lives BESIDE the tree, not inside it, so wgpu-native/ stays
byte-identical to its archives (not even an added file).

COMMITTING wgpu-native/: wgpu-native/.gitignore and
wgpu-native/ffi/webgpu-headers/.gitignore are part of the archives; a nested
.gitignore wins over ours. Check after any bump that nothing of the tree is
ignored:
    git ls-files --others --ignored --exclude-standard wgpu-native-tools/wgpu-native
(empty on 2026-10-11).

VERIFYING THE SNAPSHOT AGAINST ITS ARCHIVES (no network needed)

    (cd upstream-downloads && sha256sum -c SHA256SUMS)
    mkdir -p /tmp/wv && tar -xzf upstream-downloads/wgpu-native-29.0.1.1.tar.gz -C /tmp/wv
    rmdir /tmp/wv/wgpu-native-29.0.1.1/ffi/webgpu-headers
    tar -xzf upstream-downloads/webgpu-headers-673658bc2bd70ec39fc55ebe6bb0173cf6d0a603.tar.gz -C /tmp/wv
