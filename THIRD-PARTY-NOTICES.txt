THIRD-PARTY SOFTWARE NOTICES AND INFORMATION

This repository produces three packages: CodeBrix.WebGpu.Native, a thin,
generated .NET binding over the native codebrix_wgpu libraries it P/Invokes
into; CodeBrix.WebGpu.Skia, which shares a GPU device between that binding
and SkiaSharp; and CodeBrix.WebGpu.Graphics, a graphics layer (resources,
pipelines, 2D and 3D renderers, presentation) over the binding. Several things
in this repository and in the packages come from other people; all of them
are covered below.

  1. THE SHIPPED BINARIES. The CodeBrix.WebGpu.Native package's
     runtimes/<rid>/native/ folders contain
     libcodebrix_wgpu.so / libcodebrix_wgpu.dylib / codebrix_wgpu.dll. Each is
     built from the codebrix-wgpu Rust crate in wgpu-native-tools/codebrix-wgpu/
     (written for this repository, MIT), which links wgpu-native, which in turn
     compiles in the wgpu engine crates and their dependencies from crates.io.
     Beside every binary is LICENSE-WgpuNative.txt - composed from
     wgpu-native-tools/licenses/ by wgpu-native-tools/licenses/
     compose-license-wgpunative.sh - with the full licence text of wgpu-native,
     of webgpu-headers and of EVERY crate compiled into the library, grouped by
     licence. That file, identical on every runtime identifier, is the complete
     notice for the binaries; it is not repeated here.

  2. THE VENDORED SOURCE. wgpu-native-tools/wgpu-native/ is an unmodified copy
     of the wgpu-native release (gfx-rs/wgpu-native, tag v29.0.1.1; "wgpu 29.0.3
     via wgpu-native v29.0.1.1"), and wgpu-native-tools/wgpu-native/ffi/
     webgpu-headers/ an unmodified copy of webgpu-native/webgpu-headers at the
     commit that release pins (673658bc2bd70ec39fc55ebe6bb0173cf6d0a603). The
     archives and their SHA-256 sums are in wgpu-native-tools/upstream-downloads/.
     wgpu-native-tools/wgpu-hal/ is an unmodified copy of the wgpu-hal 29.0.3
     crate (gfx-rs/wgpu, crates.io; "MIT OR Apache-2.0", used under MIT; its
     LICENSE.MIT is in LICENSE-WgpuNative.txt, as for every crate compiled in),
     vendored because patches/0010 changes it; its .crate archive is in
     upstream-downloads/ as well.
     Build-time patches live in wgpu-native-tools/patches/ and are applied to a
     scratch copy only; the vendored trees are never edited.

  3. THE GENERATED BINDING. src/CodeBrix.WebGpu.Native/Generated/*.g.cs is
     generated by tools/CodeBrix.WebGpu.BindingGenerator from:
       - webgpu-headers' webgpu.yml and schema.json (BSD-3-Clause; the API
         description and its documentation text, which becomes the XML
         documentation of the generated members);
       - wgpu-native-tools/specs/wgpu.yml - a transcription, in the
         webgpu-headers schema, of wgpu-native's ffi/wgpu.h (MIT), started from
         the wgpu.yml file of wgpu-native trunk commit
         6f7d734be9bb5d1b3f0f48c9eb3019eec1eaa21a (that file carries
         "Copyright 2019-2023 wgpu-native developers, SPDX-License-Identifier:
         BSD-3-Clause"); its doc text is taken from wgpu.h's comments;
       - wgpu-native-tools/specs/codebrix.yml (this repository, MIT).
     The generator follows the naming and value rules of webgpu-headers'
     reference Go generator (gen/, BSD-3-Clause); no Go code was copied - the
     generator is a new C# program.
     The same generator writes the native-module files
     src/CodeBrix.WebGpu.Native/include/codebrix_wgpu_procs.h and
     codebrix_wgpu_procs.rs from those inputs (the Rust file restates the C
     types of webgpu.h and wgpu.h).

  3a. THE SHIPPED C HEADERS. The CodeBrix.WebGpu.Native package's include/
     folder carries, unmodified, webgpu-headers' webgpu.h (BSD-3-Clause) and
     wgpu-native's ffi/wgpu.h (MIT) from the vendored trees above, beside
     codebrix_wgpu.h (this repository, MIT), the two generated files above and
     a copy of LICENSE-WgpuNative.txt, whose PART 1 (wgpu-native, MIT) and
     PART 2 (webgpu-headers, BSD-3-Clause) are the notices for the two
     headers.

  4. BUILD-TIME TOOLS. The binding generator uses the NuGet packages
     CodeBrix.YamlParse.MitLicenseForever and
     CodeBrix.Templating.BsdLicenseForever. They are tools only: nothing from
     them is compiled into the CodeBrix.WebGpu.Native assembly or shipped in
     its package.

  5. SKIASHARP. CodeBrix.WebGpu.Skia references the SkiaSharp NuGet package
     (mono/SkiaSharp, MIT) as an ordinary package dependency. No SkiaSharp
     source or binary is copied into this repository or into the
     CodeBrix.WebGpu.Skia package; SkiaSharp and its native assets reach an
     application through NuGet under their own licences. CodeBrix.WebGpu.Skia
     is written for this repository (MIT). Its licence text follows (section 4).

  6. CODEBRIX.WEBGPU.GRAPHICS is written for this repository (MIT). It contains
     no third-party code; its WGSL shaders are this repository's own (its
     Radiance .hdr decoder follows the logic of the public-domain stb_image.h
     HDR loader - public domain / MIT-0, no notice required). Besides
     CodeBrix.WebGpu.Native it references two NuGet packages as ordinary
     package dependencies, each reaching an application through NuGet under
     its own licence (nothing of them is copied into this repository or into
     the Graphics package):
       - CodeBrix.Imaging.ApacheLicenseForever (image decoding and encoding;
         Apache License 2.0 - a fork of SixLabors.ImageSharp / Fonts by its
         own repository, ellisnet/CodeBrix.Imaging, which carries its notices);
       - CodeBrix.Graphics3D.Gltf2.MitLicenseForever (glTF 2.0 reading; MIT).
     The Graphics package itself stays MIT. Its tests include a few
     public-domain 3D models and an HDRI, listed with their credits in
     section 6 below.

  7. THE SAMPLES. samples/WebGpuModelViewer and samples/WebGpuModelViewer.Android
     (which links the desktop sample's sources and models) are not part of any
     package. They reference the NuGet packages
     CodeBrix.Graphics3D.Gltf2.MitLicenseForever, CodeBrix.Sdl3.ZlibLicenseForever,
     SkiaSharp and SkiaSharp.NativeAssets.* (each under its own licence,
     reaching the samples through NuGet), and include a few public-domain 3D
     models, listed with their credits in section 5 below.

  8. THE TEST PROJECTS are not part of any package. Besides the projects of
     this repository they reference xunit.v3, xunit.runner.visualstudio,
     Microsoft.NET.Test.Sdk, SilverAssertions.ApacheLicenseForever and
     SkiaSharp.NativeAssets.Linux as NuGet packages (each under its own
     licence) and include the public-domain models and HDRI of section 6.
